# AI Rule-Based Chatbot

## About
A terminal-based AI chatbot developed using Python. It uses if-else rules, user input, functions, and a while loop to interact with the user through a series of questions.

## Features
- Takes user input and interacts with the user
- Asks about name, location, feelings, goals, and interests
- Provides responses using if-else logic
- Includes a basic AI quiz
- Explains how the chatbot works
- Allows the user to exit by typing `bye` or `thankyou`

## Technologies Used
- Python
- If-Else Statements
- Functions
- While Loop
- User Input

## How to Run

Run the Python file in VS Code or terminal:

```bash
python chatbot.py
